# Merge sorted arrays

`mergeSortedArrays(arrayA, arrayB)` merges two arrays already sorted in ascending numeric order.

It produces a new sorted array, keeps duplicate values and does not modify either input. A two-pointer scan takes O(n + m) time and O(n + m) space.

The function assumes its inputs are already sorted.

Run: `node merge-sorted-arrays/index.mjs`.
